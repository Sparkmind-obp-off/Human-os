# Human OS

Human OS is a standalone human-centered AI operating layer designed to help a person think, organize, communicate, decide, and execute across life and work through a persistent, voice-first interface.

## Product Thesis

Human OS does not attempt to replace human relationships or impersonate a specific person. It provides a dependable digital operating layer that can be present across activities while keeping the human as the owner and final decision-maker.

Core loop:

**Sense → Understand → Plan → Act → Verify → Remember → Reflect**

## Initial North Star

> "I can call Human OS and say what I need; it understands the context, coordinates the right tools, performs safe actions, and brings important decisions back to me."

## Principles

- Human agency first
- Voice-first, not voice-only
- Persistent context with explicit memory controls
- Action over conversation
- Verification before consequential actions
- Privacy and least privilege by default
- Transparent autonomy levels
- Human relationships remain human
- Modular connector architecture
- Build only what can be validated
