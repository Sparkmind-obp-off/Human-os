# Human OS — Product Definition

## 1. Product
Human OS is a persistent, voice-first personal operating layer for reasoning, coordination, memory, and action.

## 2. Core Experience
User: "Human OS, handle this."

System:
1. Captures voice.
2. Understands intent and context.
3. Determines whether clarification is needed.
4. Plans the work.
5. Selects permitted tools.
6. Executes low-risk actions or asks for approval.
7. Verifies outcomes.
8. Reports what happened.
9. Stores only useful, authorized memory.

## 3. Capability Domains
- Personal organization
- Work/project coordination
- Research
- Communication drafting
- Calendar/task coordination
- File and knowledge retrieval
- Business-system orchestration
- Browser/tool execution
- Health/lifestyle-adjacent organization without pretending to provide professional care
- Reflection and planning

## 4. Interaction Modes
- Live voice
- Voice command
- Text
- Structured activity view
- Approval cards
- Activity/audit timeline

## 5. Autonomy Levels
L0: Explain only
L1: Suggest
L2: Prepare
L3: Execute reversible actions
L4: Execute pre-authorized workflows with monitoring
L5: Never autonomous: actions requiring explicit human decision by policy

## 6. Core UX Rule
The user should always be able to answer: "What is Human OS doing, why, with which tool, and what happens next?"
