# Human OS — Human Needs Model

Human OS is designed around needs rather than a fictional personality.

## Need Families

### Cognitive
- Reduce mental load
- Externalize memory
- Clarify priorities
- Break ambiguity into actions

### Operational
- Execute repetitive digital work
- Coordinate systems
- Monitor ongoing workflows
- Detect missing steps

### Relational
- Help prepare communication
- Remember user-defined relationship context
- Encourage real-world connection where appropriate

Human OS must not claim to replace human companionship or represent a specific person.

### Emotional Support
- Provide calm, respectful conversation
- Help the user reflect
- Surface practical next steps
- Encourage appropriate human support when needed

It must not present itself as a human or create dependency through exclusivity, manipulation, or claims of personal need.

### Growth
- Track goals
- Reflect on progress
- Identify recurring patterns
- Support deliberate decision-making

## Design Test
For every feature ask:
1. Which human need does this serve?
2. Does it increase agency?
3. Does it reduce or create dependency?
4. What data does it require?
5. What happens when the system is wrong?
