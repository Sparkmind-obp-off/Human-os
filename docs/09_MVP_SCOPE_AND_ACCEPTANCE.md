# Human OS — MVP Scope & Acceptance

## MVP Objective
Prove that a person can use voice to delegate a small set of real digital tasks and receive trustworthy execution feedback.

## In Scope
1. Voice/text entry
2. Persistent session context
3. Basic user memory with inspect/delete
4. Task creation and planning
5. One or two low-risk connectors
6. Approval workflow
7. Action log
8. Verification/result reporting
9. Basic background task state
10. Kill switch

## Out of Scope
- Fully autonomous life management
- Dozens of integrations
- Emotional/romantic persona simulation
- High-risk autonomous decisions
- Always-on surveillance

## Acceptance Criteria
- User can issue a natural-language/voice task.
- System produces an understandable plan.
- User can approve/deny proposed actions.
- Executed action has an auditable result.
- Failed actions do not silently disappear.
- User can inspect/delete stored memory.
- Connector credentials are not exposed to the model unnecessarily.
