# Human OS — Open Questions

1. Which first workflow demonstrates repeatable value?
2. Which realtime voice stack best satisfies latency, privacy, and cost requirements?
3. Which model should own planning versus execution?
4. What memory should be persistent by default?
5. Which connectors are essential for the first user cohort?
6. How should background tasks notify users without becoming intrusive?
7. What is the minimum trustworthy autonomy level?
8. Which parts should be hosted directly versus delegated to external execution providers?
9. What metrics define "reliable enough" for autonomous workflows?
10. Which business model survives actual usage costs?

These questions should be answered through experiments and explicit ADRs, not assumptions.
